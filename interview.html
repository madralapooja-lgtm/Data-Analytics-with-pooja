Interview Prep

Practice explaining concepts clearly instead of memorizing one-line definitions.

SQL

What is a JOIN? WHERE vs HAVING? CTE vs subquery? ROW_NUMBER vs RANK? Find the second-highest salary.

Excel

Explain PivotTables, XLOOKUP, IF, COUNTIF, data validation and how you would clean a messy sheet.

Power BI

Power Query vs DAX? Measure vs column? What is a relationship? Why use a calendar table?

Projects

What was the business problem? What data did you use? What transformations did you perform?

Behavioral

Prepare concise examples for ownership, mistakes, teamwork, learning something quickly and handling ambiguity.

Self Introduction

Use: present → relevant experience → skills → project evidence → role you are targeting.

Answer framework: define the concept → give a tiny example → explain when you would use it → mention one limitation or common mistake.
