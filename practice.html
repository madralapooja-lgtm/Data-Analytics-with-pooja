PRACTICE LAB

Solve before you reveal.

Practice SQL, Excel, DAX and real-world reasoning by difficulty.

SQL • EASY

Filter customers

Return customers from Bangalore.

SELECT Name, City FROM Customers WHERE City='Bangalore';
WHERE filters rows before aggregation.
EXCEL • EASY

Count paid orders

Count rows where Status is Paid.

=COUNTIF(StatusRange,"Paid")
COUNTIF handles one condition; COUNTIFS handles multiple.
SQL • MEDIUM

Second-highest salary

Find the second-highest distinct salary.

SELECT MAX(Salary) FROM Employees WHERE Salary < (SELECT MAX(Salary) FROM Employees);
The outer MAX finds the largest value below the overall maximum.
DAX • MEDIUM

Measure vs column

When is a measure usually preferable?

Measure → filter context
Column → row-level storage
Measures are usually preferred for dynamic aggregations responding to report filters.
SQL • HARD

Top 3 per category

Rank products within each category.

DENSE_RANK() OVER(PARTITION BY Category ORDER BY Revenue DESC)
PARTITION BY restarts ranking for each category; choose the ranking function based on tie requirements.
POWER BI • HARD

Slow dashboard

A report takes 30 seconds to load. What do you investigate?

Model → relationships → DAX → visuals → source
Start with model size/schema, high-cardinality fields, expensive measures and unnecessary visuals before changing everything at once.
